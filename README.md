# Isabella Fasula | Portfolio

Portfolio website for Isabella Fasula: Graphic & Game Designer and 3D Modeler.
Live site: https://bellafasula.com

## What is in this folder
- `index.html` : the whole website (pages, styling and scripts)
- `images/` : every picture used on the site (compressed WebP files)
- `resume.pdf` : the file the "Download resume" button gives out. Replace this file to update the resume.
- `edits.json` : saved text edits for the site
- `preview.jpg` : the picture shown when the link is shared on LinkedIn, Messages, etc.

## Updating the site
Upload the new files to this repository and choose "Replace". Keep the same file names.
